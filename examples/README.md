# Synthetic software inputs

All files under `synthetic/` were generated during portfolio preparation using `python -m tools.generate_demo_inputs`. They are not recorded images, experimental samples or original training media. OpenCV generates the marker patterns. Individual marker PNGs include white margins for optional physical printing; printing them does not itself validate camera detection.

The README previews are actual outputs of the image-mode commands on these generated inputs. A camera-free single-image decode does not confirm a scan sequence or physical task. No real camera image is bundled in this repository.
